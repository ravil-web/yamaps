# Инструкция по запуску парсера

## Основной файл входа
**`run_full_cycle.py`** - это основной файл для запуска парсера с автоматическим созданием дашборда.

## Как запустить

### 1. Базовый запуск
```bash
python run_full_cycle.py
```

### 2. Что происходит при запуске:
1. **Запрос имени проекта** - введите название для вашего проекта парсинга
2. **Запрос URL** - введите URL Яндекс.Карт или нажмите Enter для использования по умолчанию
3. **Запрос количества предприятий** - введите количество или нажмите Enter для использования значения из `config.py`
4. **Парсинг данных** - автоматически запускается с исправленной прокруткой
5. **Создание дашборда** - автоматически генерируется HTML дашборд
6. **Предложение открыть дашборд** - можете открыть результат в браузере

## Настройка количества предприятий

### В файле `config.py`:
```python
# Количество предприятий для парсинга (0 = все найденные)
TARGET_BUSINESSES_COUNT = 0  # Все найденные
# TARGET_BUSINESSES_COUNT = 15  # Конкретное количество
```

### При запуске:
- Если в `config.py` установлено `0` - парсер найдет все доступные предприятия
- Если установлено конкретное число (например, `15`) - парсер найдет 15 предприятий
- При запуске можете переопределить это значение

## Все исправления применены автоматически

При запуске `run_full_cycle.py` автоматически используются:

✅ **Исправленная прокрутка блока** - прокрутка только блока с предприятиями, а не всей страницы  
✅ **Устранены ошибки** - нет ошибок `element not interactable`  
✅ **Использование конфигурации** - значение `TARGET_BUSINESSES_COUNT` из `config.py`  
✅ **Поддержка "всех найденных"** - значение `0` означает парсинг всех предприятий  
✅ **Оптимизированная скорость** - быстрая и эффективная прокрутка  

## Примеры запуска

### Парсинг всех найденных предприятий:
```bash
python run_full_cycle.py
# Введите имя проекта: Стоматология_Ростов_2025
# URL (Enter для по умолчанию): [Enter]
# Количество предприятий (Enter для всех найденных): [Enter]
```

### Парсинг конкретного количества:
```bash
python run_full_cycle.py
# Введите имя проекта: Тест_10_предприятий
# URL (Enter для по умолчанию): [Enter]
# Количество предприятий: 10
```

### Парсинг с кастомным URL:
```bash
python run_full_cycle.py
# Введите имя проекта: Кафе_Москва
# URL: https://yandex.ru/maps/213/moscow/search/кафе/
# Количество предприятий: 20
```
