# 🏥 Парсер стоматологических клиник + Дашборд

Интегрированное решение для парсинга данных стоматологических клиник с Яндекс Карт и их визуализации в веб-дашборде.

## 📋 Возможности

### 🔍 Парсер
- Автоматический поиск стоматологических клиник на Яндекс Картах
- Извлечение контактной информации (название, адрес, телефоны, сайт)
- Парсинг товаров и услуг с ценами
- Интеллектуальная прокрутка для загрузки всех предприятий
- Сохранение данных в JSON и CSV форматах

### 📊 Дашборд
- **Интерактивные таблицы** с фильтрацией и сортировкой
- **Детальная информация** о каждом предприятии в модальных окнах
- **Аналитические графики** по ценам, количеству услуг и категориям
- **Фильтрация товаров** по предприятиям и ценовому диапазону
- **Статистические карточки** с ключевыми метриками

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements_full.txt
```

### 2. Настройка конфигурации
Отредактируйте `config.py`:
```python
# Количество предприятий для парсинга
TARGET_BUSINESSES_COUNT = 10

# URL для поиска (можно изменить город/тип предприятий)
SEARCH_URL = "https://yandex.ru/maps/39/rostov-na-donu/search/..."
```

### 3. Запуск

#### Вариант А: Полный цикл (парсинг + дашборд)
```bash
python run_parser_and_dashboard.py
```
Выберите опцию `3` для полного цикла.

#### Вариант Б: Отдельные компоненты

**Только парсинг:**
```bash
python main.py
```

**Базовый дашборд:**
```bash
python run_dashboard.py
```

**Улучшенный дашборд:**
```bash
python enhanced_dashboard.py
```

## 📱 Интерфейс дашборда

### Главная страница
- 📊 **Статистические карточки**: общее количество предприятий, товаров, средняя цена
- 📋 **Три основные вкладки**: Предприятия, Товары/услуги, Аналитика

### Вкладка "Предприятия"
- Таблица со всеми найденными предприятиями
- Колонки: название, рейтинг, адрес, категории, телефоны, количество товаров, ценовые показатели
- Клик по строке открывает **детальную информацию** в модальном окне
- Фильтрация и сортировка по всем полям

### Вкладка "Товары/услуги"
- Список всех товаров и услуг от всех предприятий
- **Фильтрация по предприятию** через dropdown
- **Ценовой фильтр** с помощью слайдера
- Поиск по названию товара/услуги

### Вкладка "Аналитика"
- 📈 **График ТОП-10** предприятий по количеству услуг
- 💰 **График ТОП-10** предприятий по средней цене
- 📊 **Гистограмма** распределения цен
- 🥧 **Круговая диаграмма** распределения по категориям

## ⚙️ Конфигурация

### config.py - основные настройки
```python
# Поиск
TARGET_BUSINESSES_COUNT = 10  # Количество предприятий
TARGET_PRODUCTS_COUNT = 100   # Количество товаров на предприятие

# Задержки (секунды)
DELAYS = {
    'page_load': 5,
    'scroll': 1,
    'element_click': 2
}

# Сохранение
SAVE_OPTIONS = {
    'save_json': True,
    'save_csv': True,
    'save_products_separate': True
}
```

## 🔧 Решение проблем

### Парсер не находит предприятия
1. Проверьте URL в `config.py`
2. Увеличьте задержки в `DELAYS`
3. Проверьте интернет-соединение

### Дашборд не запускается
1. Убедитесь, что есть данные в `parsing_results/`
2. Проверьте установку зависимостей: `pip install -r requirements_full.txt`
3. Попробуйте другой порт: измените `port=8050` в коде

### Браузер не открывается автоматически
Откройте вручную: http://localhost:8050 (или 8051 для enhanced_dashboard.py)
