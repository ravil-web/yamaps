# Инструкция по установке и запуску парсера Яндекс.Карт

## Системные требования

- **Python**: версия 3.8 или выше
- **ОС**: Windows 10/11, macOS, Linux
- **Память**: минимум 4 ГБ RAM
- **Место на диске**: 500 МБ свободного места

## Установка

### 1. Установка Python

Если Python не установлен:

**Windows:**
1. Скачайте Python с официального сайта: https://www.python.org/downloads/
2. При установке обязательно отметьте "Add Python to PATH"
3. Проверьте установку: `python --version`

**macOS:**
```bash
# Через Homebrew
brew install python3

# Или скачайте с python.org
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt update
sudo apt install python3 python3-pip
```

### 2. Установка зависимостей

Откройте командную строку/терминал в папке с парсером и выполните:

```bash
# Установка всех зависимостей
pip install -r requirements_parser.txt

# Или установка по одной (если возникают проблемы)
pip install selenium==4.15.2
pip install webdriver-manager==4.0.1
pip install beautifulsoup4==4.12.2
pip install requests==2.31.0
pip install pandas==2.1.3
pip install openpyxl==3.1.2
pip install jinja2==3.1.2
```

### 3. Проверка установки

```bash
# Проверка Python
python --version

# Проверка pip
pip --version

# Проверка установленных пакетов
pip list | grep selenium
```

## Настройка

### 1. Настройка конфигурации

Откройте файл `config.py` и настройте параметры:

```python
# Количество предприятий для парсинга
TARGET_BUSINESSES_COUNT = 0  # 0 = все найденные, или конкретное число

# Настройки браузера
HEADLESS_MODE = False  # True для работы без окна браузера
BROWSER_TIMEOUT = 30   # Таймаут ожидания элементов (секунды)
```

### 2. Настройка поиска

В файле `run_full_cycle.py` измените URL поиска:

```python
# Замените на нужный вам поиск
search_url = "https://yandex.ru/maps/39/rostov-na-donu/search/стоматология/?ll=39.806284%2C47.275656&z=12"
```

## Результаты

### 1. Файлы результатов

После парсинга создаются следующие файлы:

- `parsing_results/` - папка с результатами парсинга
- `dashboard/` - папка с HTML дашбордами
- `output/` - папка с Excel файлами

### 2. Структура результатов

```
parsing_results/
├── session_YYYYMMDD_HHMMSS/
│   ├── businesses_data.json
│   ├── parsing_log.txt
│   └── summary.txt
dashboard/
├── dashboard_YYYYMMDD_HHMMSS.html
└── modern_dashboard_YYYYMMDD_HHMMSS.html
output/
└── businesses_YYYYMMDD_HHMMSS.xlsx
```

## Устранение проблем

### 1. Ошибка "ChromeDriver not found"

```bash
# Установка ChromeDriver через webdriver-manager
pip install --upgrade webdriver-manager
```

### 2. Ошибка "Permission denied"

**Windows:**
- Запустите командную строку от имени администратора

**macOS/Linux:**
```bash
sudo pip install -r requirements_parser.txt
```

### 3. Ошибка "Module not found"

```bash
# Переустановка зависимостей
pip uninstall -r requirements_parser.txt -y
pip install -r requirements_parser.txt
```

### 4. Медленная работа

1. Увеличьте `BROWSER_TIMEOUT` в `config.py`
2. Установите `HEADLESS_MODE = True`
3. Закройте другие программы

### 5. Парсер не находит предприятия

1. Проверьте URL поиска
2. Увеличьте `TARGET_BUSINESSES_COUNT`
3. Проверьте интернет-соединение

## Поддержка

При возникновении проблем:

1. Проверьте логи в папке `parsing_results/`
2. Убедитесь, что все зависимости установлены
3. Проверьте версию Python (должна быть 3.8+)
4. Убедитесь, что Chrome/Chromium установлен

## Обновление

Для обновления парсера:

```bash
# Обновление зависимостей
pip install -r requirements_parser.txt --upgrade

# Обновление webdriver-manager
pip install --upgrade webdriver-manager
```

## Безопасность

- Не передавайте логины/пароли в URL
- Используйте VPN при необходимости
- Регулярно обновляйте зависимости
- Не запускайте парсер слишком часто
