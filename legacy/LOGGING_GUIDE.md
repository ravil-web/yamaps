# 📋 Руководство по логированию парсера

## 🔧 Что добавлено

Полное логирование во все модули парсера:

### 📊 Уровни логирования
- **DEBUG** - детальная информация для отладки
- **INFO** - основная информация о процессе
- **WARNING** - предупреждения
- **ERROR** - ошибки

### 📁 Файлы логов
- Логи сохраняются в папку `logs/`
- Имя файла: `parser_YYYYMMDD_HHMMSS.log`
- Формат: `время - модуль - уровень - [функция:строка] - сообщение`

## 🚀 Как запустить

### Простой запуск с логированием:
```bash
python main.py "https://yandex.ru/maps/39/rostov-na-donu/search/стоматология/" --save-format excel
```

### Запуск с детальным логированием:
```bash
# В коде изменить уровень логирования на DEBUG
python main.py "URL" --save-format all --max-pages 2
```

## 🔍 Отладка проблем

### 1. **Проблемы с браузером**
```bash

```

### 2. **Проблемы с извлечением данных**

## 🛠️ Настройка логирования

### Изменение уровня логирования:
В `src/main_parser.py` в методе `_setup_logging()`:

```python
# Для детального логирования
logger.setLevel(logging.DEBUG)

# Для основного логирования
logger.setLevel(logging.INFO)

# Только ошибки
logger.setLevel(logging.ERROR)
```

### Изменение формата логов:
```python
# Текущий формат
log_format = '%(asctime)s - %(name)s - %(levelname)s - [%(funcName)s:%(lineno)d] - %(message)s'

# Простой формат
log_format = '%(asctime)s - %(levelname)s - %(message)s'
```
