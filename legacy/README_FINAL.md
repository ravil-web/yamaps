# 🚀 Парсер Яндекс.Карт с HTML Дашбордом

Полная система для парсинга предприятий с Яндекс.Карт с автоматическим созданием интерактивного HTML дашборда.

## 📋 Возможности

### 🔍 Парсинг данных
- Извлечение полной информации о предприятиях
- Сбор товаров и услуг с ценами
- Получение контактов (телефоны, сайты, соцсети)
- Анализ рейтингов и отзывов
- Сбор адресов и режима работы

### 📊 HTML Дашборд
- **Аккордеон предприятий** - удобная навигация
- **Детальная информация** - все данные о предприятии
- **Список товаров** - карточки с ценами и описаниями
- **Адаптивный дизайн** - работает на всех устройствах
- **Интерактивность** - анимации и hover-эффекты

## 🛠️ Быстрый старт

### 1. Автоматический запуск (рекомендуется)
```bash
python run_parser_with_dashboard.py
```

### 2. Ручное создание дашборда
```bash
# Создать дашборд для всех JSON файлов
python create_dashboard.py

# Создать дашборд для конкретного файла
python create_dashboard.py output/final_data_20241201_143022.json
```

### 3. Прямой запуск парсера
```bash
python final_working_parser.py
```

## 🔧 Настройка

### Изменение параметров парсинга
В `run_parser_with_dashboard.py`:
```python
url = "ваш_url_яндекс_карт"
target_count = 5  # количество предприятий
```

### Изменение стилей дашборда
В `html_dashboard_generator.py` отредактируйте CSS:
```python
self.css_styles = """
<style>
/* Ваши стили */
</style>
"""
```

### Добавление новых полей
В методе `generate_business_html()`:
```python
<div class="info-group">
    <div class="info-title">🏷️ Новое поле</div>
    <div class="info-content">
        {business.get('new_field', 'Не указано')}
    </div>
</div>
```

## 🐛 Устранение неполадок

### Парсер не работает
1. Проверьте подключение к интернету
2. Убедитесь, что Chrome установлен
3. Проверьте URL на корректность

### Дашборд не создается
1. Проверьте наличие JSON файлов в `output/`
2. Убедитесь в корректности структуры данных
3. Проверьте права доступа к папке `dashboards/`

### Пустые данные
1. Проверьте селекторы в парсере
2. Убедитесь, что страница загружается корректно
3. Попробуйте другой URL

## 📞 Поддержка
