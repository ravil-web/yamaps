# 🦷 Парсер Yandex Maps для стоматологических клиник

Автоматизированная система парсинга данных стоматологических клиник с Яндекс.Карт с последующим созданием интерактивного дашборда для сравнения цен на услуги.

## ✨ Основные возможности

### 🔍 Парсинг данных
- **Умный поиск предприятий**: Автоматическая прокрутка списка результатов для нахождения всех доступных предприятий
- **Полная информация о клиниках**: Название, адрес, телефон, рейтинг, категории, веб-сайт
- **Детальные услуги и цены**: Парсинг всех доступных услуг с ценами
- **Отзывы клиентов**: Сбор отзывов с оценками и текстом
- **Устойчивость к блокировкам**: Использование undetected-chromedriver

### 💰 Сравнение цен (главная фича)
- **Умное сопоставление услуг**: Алгоритм нечеткого поиска для группировки похожих услуг
- **Интерактивные таблицы**: Сравнение цен по предприятиям с выделением лучших предложений
- **Фильтрация и группировка**: Автоматическое объединение услуг типа "Лечение кариеса", "Лечение среднего кариеса"
- **Клиентский интерфейс**: Простой и понятный дашборд без лишней статистики

### 📊 Дашборд и отчеты
- **Статический HTML дашборд**: Не требует запущенного сервера
- **Адаптивный дизайн**: Корректно отображается на всех устройствах
- **Сессионный подход**: Отдельный дашборд для каждого парсинга
- **Экспорт данных**: CSV и JSON форматы

## 🚀 Быстрый старт

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск парсера
```bash
python main_parser.py
```

### Создание дашборда для существующих данных
```bash
python create_dashboard_for_session.py "название_сессии"
```

## 📁 Структура проекта

```
parser_ya_maps/
├── main_parser.py              # Основной парсер
├── single_business_parser.py   # Парсер отдельных предприятий
├── client_dashboard.py         # Генератор дашборда
├── create_dashboard_for_session.py  # Создание дашборда для сессии
├── config.py                   # Конфигурация
├── requirements.txt            # Зависимости
└── parsing_results/            # Результаты парсинга (по сессиям)
    └── parsing_YYYYMMDD_HHMMSS/
        ├── businesses/         # Данные предприятий
        ├── logs/              # Логи парсинга
        └── client_dashboard_*.html  # Дашборд
```

## ⚙️ Конфигурация

Основные настройки в `config.py`:
- `TARGET_BUSINESSES_COUNT`: Количество предприятий для парсинга
- `TARGET_PRODUCTS_COUNT`: Количество услуг с каждого предприятия
- `SEARCH_URL`: URL поиска на Яндекс.Картах
- `DELAYS`: Настройки задержек для обхода защиты

## 🔧 Технические особенности

### Алгоритм сравнения услуг
1. **Нормализация названий**: Удаление стоп-слов, приведение к единому виду
2. **Расчет схожести**: Комбинация текстовой схожести и пересечения ключевых слов
3. **Группировка**: Объединение услуг с схожестью >60%
4. **Ранжирование**: Сортировка по популярности (количеству предприятий)

### Обход защиты Яндекс.Карт
- Использование undetected-chromedriver
- Имитация человеческого поведения (прокрутка, задержки)
- Правильная обработка динамической загрузки контента
- Умная работа с контейнером `ul.search-list-view__list`
