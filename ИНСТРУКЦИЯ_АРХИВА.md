## ⚙️ Настройка

### 1. Настройка поиска
Отредактируйте `run_full_cycle.py`:
```python
# Замените на нужный вам поиск
search_url = "https://yandex.ru/maps/39/rostov-na-donu/search/стоматология/?ll=39.806284%2C47.275656&z=12"
```

### 2. Настройка количества предприятий
Отредактируйте `config.py`:
```python
TARGET_BUSINESSES_COUNT = 0  # 0 = все найденные, или конкретное число
```

## 🔧 Устранение проблем

### ChromeDriver не найден
```bash
pip install --upgrade webdriver-manager
```

### Медленная работа
1. Установите `HEADLESS_MODE = True` в `config.py`
2. Закройте другие программы

### Парсер не находит предприятия
1. Проверьте URL поиска
2. Увеличьте `TARGET_BUSINESSES_COUNT`
3. Проверьте интернет-соединение
