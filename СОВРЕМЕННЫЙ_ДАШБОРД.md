# 🚀 Современный дашборд для парсинга Яндекс.Карт

## ✨ Особенности

### 🎨 Современный дизайн
- **Градиентные фоны** и современная типографика
- **Анимации** и плавные переходы
- **Адаптивный дизайн** для всех устройств
- **Интерактивные элементы** с hover-эффектами

### 📊 Группировка и сравнение
- **Группировка товаров по предприятиям** - каждый товар привязан к своему предприятию
- **Сравнение товаров между предприятиями** - таблица показывает одинаковые товары у разных предприятий
- **Интерактивные табы** для переключения между просмотрами

### 📁 Сохранение в папке парсинга
- Дашборд создается автоматически в папке `output/dashboard/` после каждого парсинга
- Удобная организация файлов по сессиям парсинга
- Все файлы одной сессии находятся в одной папке

## 🛠️ Как использовать

### 1. Автоматическое создание (рекомендуется)
```bash
# Простой запуск
python run_parser_auto_dashboard.py

# С указанием URL
python run_parser_auto_dashboard.py "https://yandex.ru/maps/39/rostov-na-donu/search/стоматология/"

# С указанием URL и количества предприятий
python run_parser_auto_dashboard.py "https://yandex.ru/maps/39/rostov-na-donu/search/стоматология/" 5
```
Дашборд создается автоматически после каждого парсинга в папке `output/dashboard/`.

### 2. Ручное создание из существующих данных
```bash
# Для всех JSON файлов
python create_modern_dashboard.py

# Для конкретного файла
python create_modern_dashboard.py output/final_data_20241201_143022.json
```

### 3. Прямой запуск генератора
```bash
python modern_dashboard_generator.py
```

## 🔧 Настройка

### Изменение стилей
В `modern_dashboard_generator.py` отредактируйте CSS:
```python
self.css_styles = """
<style>
/* Ваши стили */
</style>
"""
```

### Добавление новых полей
В методе `generate_business_card()`:
```python
<div class="info-item">
    <i>🏷️</i>
    <span>{business.get('new_field', 'Не указано')}</span>
</div>
```

## 🎨 Особенности дизайна

### Цветовая схема
- **Основные цвета**: синие градиенты (#667eea → #764ba2)
- **Акценты**: зеленый для цен (#10b981)
- **Текст**: темно-серый (#1e293b)
- **Фон**: белый с тенями

### Анимации
- **Появление карточек** при прокрутке
- **Hover-эффекты** на карточках
- **Плавные переходы** между табами
- **Трансформации** при наведении

### Типографика
- **Шрифт**: Inter (Google Fonts)
- **Заголовки**: жирные (700-800)
- **Текст**: средний вес (400-500)
- **Размеры**: адаптивные
