# 📁 Управление сессиями парсинга

## ✨ Новый функционал

Теперь каждый парсинг создает отдельную именованную папку для полной организации данных.

## 📋 Структура папок

### Старая структура:
```
parsing_results/
├── businesses/
│   ├── Стоматология_1/
│   └── Стоматология_2/
└── logs/
```

### Новая структура:
```
parsing_results/
├── Стоматология_Ростов_2025/          ← Именованная сессия
│   ├── businesses/
│   │   ├── Стоматология_1/
│   │   └── Стоматология_2/
│   ├── logs/
│   │   └── main_parser_20250825.log
│   └── dashboard_Стоматология_Ростов_2025.html
├── Детские_клиники_Москва/            ← Другая сессия
│   ├── businesses/
│   ├── logs/
│   └── dashboard_Детские_клиники_Москва.html
└── parsing_20250825_143022/           ← Автоматическое имя
    ├── businesses/
    ├── logs/
    └── dashboard_parsing_20250825_143022.html
```

## 🚀 Использование

### 1. Основной парсинг с именем:
```bash
python main.py
# Запрос: "📝 Введите имя для этого парсинга:"
# Ввод: "Стоматология_Ростов_2025"
```

### 2. Полный цикл с именем:
```bash
python run_full_cycle.py
# Автоматический запрос имени сессии
```

### 3. Создание дашборда для конкретной сессии:
```bash
# Интерактивный выбор сессии
python generate_dashboard.py

# Указание конкретной сессии
python generate_dashboard.py --session "Стоматология_Ростов_2025"

# С выходным файлом
python generate_dashboard.py --session "Стоматология_Ростов_2025" --output "отчет.html" --open
```

## 📂 Правила именования

### ✅ Хорошие имена:
- `Стоматология_Ростов_2025`
- `Детские_клиники_Москва`
- `Парикмахерские_Центр_Январь`
- `Исследование_конкурентов_Q1`

### ❌ Избегать:
- Символы: `< > : " / \ | ? *`
- Слишком длинные имена (>50 символов)
- Только пробелы или пустые строки

### 🤖 Автоматические имена:
Если имя не указано: `parsing_YYYYMMDD_HHMMSS`

## 🎯 Преимущества

1. **📁 Организация**: Каждый проект в отдельной папке
2. **🔍 Легкий поиск**: По имени сессии сразу понятно содержимое
3. **📊 Изолированные отчеты**: Дашборд только для конкретной сессии
4. **📝 Отдельные логи**: Каждая сессия имеет свои логи
5. **🔄 Повторный анализ**: Можно легко пересоздать дашборд для любой сессии

## 📋 Команды для работы с сессиями

### Просмотр доступных сессий:
```bash
ls parsing_results/
```

### Создание дашборда для старой сессии:
```bash
python generate_dashboard.py --session "старое_имя_сессии"
```

### Открытие дашборда:
```bash
# Windows
start parsing_results/имя_сессии/dashboard_имя_сессии.html

# Linux/Mac
open parsing_results/имя_сессии/dashboard_имя_сессии.html
```

## 🔧 Технические детали

### Автоматические действия при парсинге:
1. Запрос имени сессии у пользователя
2. Создание папки `parsing_results/имя_сессии/`
3. Создание подпапок `businesses/` и `logs/`
4. Сохранение всех файлов в папку сессии
5. Генерация дашборда с именем сессии

### Совместимость:
- ✅ Новые сессии: полная поддержка именования
- ✅ Старые данные: работают в режиме совместимости
- ✅ Смешанный режим: можно работать и с новыми и со старыми данными

## 🎉 Примеры использования

### Исследование рынка:
```bash
# Сессия 1
python main.py
# Имя: "Стоматология_Ростов_Центр"

# Сессия 2  
python main.py
# Имя: "Стоматология_Ростов_Окраины"

# Сравнение через дашборды
python generate_dashboard.py --session "Стоматология_Ростов_Центр" --output "центр.html"
python generate_dashboard.py --session "Стоматология_Ростов_Окраины" --output "окраины.html"
```

### Мониторинг конкурентов:
```bash
# Ежемесячный парсинг
python main.py  # "Конкуренты_Январь_2025"
python main.py  # "Конкуренты_Февраль_2025"
python main.py  # "Конкуренты_Март_2025"
```

Теперь данные каждого парсинга организованы и легко доступны! 🎯
