# 🏥 Статический HTML Дашборд

Генератор статических HTML дашбордов для результатов парсинга стоматологических клиник.

## ✨ Преимущества статического дашборда

- **🚀 Быстрый**: Мгновенное открытие, никаких серверов
- **📱 Универсальный**: Работает в любом браузере без интернета
- **💾 Автономный**: Все данные включены в один HTML файл
- **🔗 Легко делиться**: Просто отправьте HTML файл
- **📊 Интерактивный**: Графики Plotly, вкладки, таблицы

## 🚀 Быстрый старт

### 1. Автоматическое создание (рекомендуется)
```bash
python main.py
```
Дашборд создается автоматически после парсинга в папке `parsing_results/`

### 2. Ручное создание дашборда
```bash
# Создать дашборд с автоматическим именем
python generate_dashboard.py

# Создать с конкретным именем
python generate_dashboard.py --output my_dashboard.html

# Создать и сразу открыть в браузере
python generate_dashboard.py --open
```

## 📊 Содержимое дашборда

### 🏠 Главная страница
- **📈 Статистические карточки**: количество предприятий, услуг, средние цены
- **🎯 Навигация**: три основные вкладки
- **📅 Метаданные**: дата создания, источник данных

### 📊 Вкладка "Аналитика"
- **График ТОП-10** предприятий по количеству услуг
- **График ТОП-10** предприятий по средней цене
- **Гистограмма** распределения цен
- **Круговая диаграмма** по категориям предприятий

### 🏥 Вкладка "Предприятия"
- **Интерактивная таблица** со всеми найденными предприятиями
- **Колонки**: название, рейтинг, адрес, категории, телефоны, ссылки
- **Ценовая аналитика**: мин/макс/средняя цена по каждому предприятию
- **Прямые ссылки** на сайты и Яндекс Карты

### 🛍️ Вкладка "Товары/услуги"
- **Группировка по предприятиям** в отдельных карточках
- **Топ-20 услуг** для каждого предприятия
- **Полная информация**: название, цена, описание
- **Счетчик услуг** для каждого предприятия

## ⚙️ Настройки

### В файле `config.py`:
```python
# Автоматическое создание дашборда после парсинга
AUTO_GENERATE_DASHBOARD = True

# Папка для сохранения результатов
FOLDER_STRUCTURE = {
    'base_folder': 'parsing_results',
    'businesses_subfolder': 'businesses'
}
```

### В файле `static_html_dashboard.py`:
- Можно настроить количество отображаемых товаров
- Изменить стили и цветовую схему
- Добавить дополнительные графики

## 🎨 Кастомизация

### Изменение количества товаров в таблице:
```python
# В методе create_products_table()
for product in products[:50]:  # Показать 50 вместо 20
```

### Добавление новых графиков:
```python
# В методе create_statistics_charts()
fig_new = px.scatter(...)
chart_new_html = pyo.plot(fig_new, output_type='div', include_plotlyjs=False)
```

### Изменение стилей:
Отредактируйте CSS в секции `<style>` в методе `generate_dashboard()`

## 🔧 Опции командной строки

```bash

--output, -o     Имя выходного файла (по умолчанию: dashboard_YYYYMMDD_HHMMSS.html)

```

## 📋 Примеры использования

### Создание дашборда после парсинга
```bash
# 1. Запустить парсинг (дашборд создается автоматически)
python main.py

# 2. Найти созданный файл
ls parsing_results/dashboard_*.html

# 3. Открыть в браузере
```

### Создание дашборда вручную
```bash
# Для текущих данных
python generate_dashboard.py --output latest_dashboard.html --open

# Для отчета
python generate_dashboard.py --output "Отчет_$(date +%d-%m-%Y).html"
```

### Отправка дашборда
```bash

# - Открыть с флешки
# - Сохранить в архив
```

## 🚨 Решение проблем

### Дашборд не создается
```bash
# Проверить наличие данных
ls parsing_results/businesses/

# Проверить зависимости
pip install pandas plotly

# Запустить с отладкой
python -c "from static_html_dashboard import StaticDashboardGenerator; StaticDashboardGenerator().generate_dashboard()"
```

### Графики не отображаются
- Проверьте интернет-соединение при первом открытии (для загрузки Plotly.js)
- Убедитесь, что браузер поддерживает JavaScript

### Кодировка нарушена
- Дашборд создается в UTF-8
- При проблемах откройте файл в браузере напрямую (не через текстовый редактор)
