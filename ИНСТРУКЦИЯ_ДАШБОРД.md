# 📊 HTML Дашборд - Быстрый старт

## 🚀 Как использовать

### 1. Автоматическое создание (рекомендуется)
```bash
python run_parser_with_dashboard.py
```
- Запускает парсер
- Автоматически создает HTML дашборд
- Открывает браузер с результатами

### 2. Создание из существующих данных
```bash
# Для всех JSON файлов
python create_dashboard.py

# Для конкретного файла
python create_dashboard.py output/final_data_20241201_143022.json
```

### 3. Прямой запуск генератора
```bash
python html_dashboard_generator.py
```

## 📁 Что создается

```
dashboards/
└── dashboard_*.html    # HTML дашборд с аккордеоном
```

## 🌐 Просмотр дашборда

1. Откройте файл `dashboards/dashboard_*.html` в браузере
2. Используйте аккордеон для навигации по предприятиям
3. Кликайте на карточки товаров
4. Используйте ссылки на телефоны и сайты

## 📊 Что показывает дашборд

- **Статистика**: количество предприятий, товаров, верифицированных
- **Аккордеон предприятий**: название, рейтинг, статус верификации
- **Детальная информация**: контакты, адрес, сайт, категории, услуги
- **Товары**: карточки с названием, ценой, описанием

## 🎯 Особенности

- ✅ Адаптивный дизайн (работает на мобильных)
- ✅ Интерактивный аккордеон
- ✅ Анимации и hover-эффекты
- ✅ Ссылки на телефоны и сайты
- ✅ Современный UI с градиентами

## 🔧 Настройка

Измените URL и количество предприятий в `run_parser_with_dashboard.py`:

```python
url = "ваш_url_яндекс_карт"
target_count = 5  # количество предприятий
```

## 📞 Поддержка

При проблемах:
1. Проверьте наличие JSON файлов в `output/`
2. Убедитесь в корректности структуры данных
3. Проверьте права доступа к папке `dashboards/`
