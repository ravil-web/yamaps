# 📊 HTML Дашборд для парсинга Яндекс.Карт

Интерактивный HTML дашборд для визуализации результатов парсинга предприятий и товаров с Яндекс.Карт.

## 🚀 Возможности

- **Аккордеон предприятий** - удобная навигация по списку предприятий
- **Детальная информация** - полные данные о каждом предприятии
- **Список товаров** - карточки товаров с ценами и описаниями
- **Адаптивный дизайн** - работает на всех устройствах
- **Интерактивность** - анимации и hover-эффекты
- **Статистика** - общая статистика по всем данным

## 📁 Структура файлов

```
parser_ya_maps_new/
├── html_dashboard_generator.py  # Генератор дашборда
├── create_dashboard.py          # Быстрое создание дашборда
├── final_working_parser.py      # Основной парсер (с интеграцией)
├── dashboards/                  # Папка с HTML дашбордами
│   └── dashboard_*.html
└── output/                      # JSON файлы с данными
    └── final_data_*.json
```

## 🛠️ Использование

### Автоматическое создание

Дашборд создается автоматически после каждого парсинга:

```bash
python final_working_parser.py
```

### Ручное создание

Создание дашборда из существующих JSON файлов:

```bash
# Создать дашборд для всех JSON файлов
python create_dashboard.py

# Создать дашборд для конкретного файла
python create_dashboard.py output/final_data_20241201_143022.json

# Запустить генератор напрямую
python html_dashboard_generator.py
```

## 📊 Что отображается в дашборде

### Заголовок
- Общая статистика (количество предприятий, товаров, верифицированных)
- Время создания дашборда

### Аккордеон предприятий
Каждое предприятие содержит:

**Заголовок аккордеона:**
- Название предприятия
- Статус верификации
- Рейтинг со звездочками
- Количество телефонов, категорий, товаров

**Детальная информация:**
- 📞 Контакты (телефоны, социальные сети)
- 📍 Адрес
- 🌐 Сайт
- 🏷️ Категории
- ⭐ Рейтинг и отзывы
- 🕒 Режим работы
- 🏆 Награды
- 🔧 Услуги

**Секция товаров:**
- 🛍️ Карточки товаров с названием, ценой, описанием
- Адаптивная сетка (до 12 товаров на предприятие)

## 🎨 Особенности дизайна

## 🔧 Настройка

### Изменение стилей

Отредактируйте CSS в `html_dashboard_generator.py`:

```python
self.css_styles = """
<style>
/* Ваши стили */
</style>
"""
```

### Добавление новых полей

В методе `generate_business_html()` добавьте новые блоки информации:

```python
<div class="info-group">
    <div class="info-title">🏷️ Новое поле</div>
    <div class="info-content">
        {business.get('new_field', 'Не указано')}
    </div>
</div>
```
