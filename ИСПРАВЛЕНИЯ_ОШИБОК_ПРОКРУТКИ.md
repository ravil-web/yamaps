# Исправления ошибок прокрутки контейнера

## Проблема
Ошибка `element not interactable` при попытке прокрутки контейнера с помощью клавиш:
```
Message: element not interactable
(Session info: chrome=136.0.7103.48)
```

## Причина
Контейнер с результатами поиска не поддерживает интерактивную прокрутку с помощью клавиш (`send_keys(Keys.PAGE_DOWN)`).

## Решение

### 1. Исправлен метод `scroll_results_container()`
```python
def scroll_results_container(self, container):
    """Прокрутка конкретного контейнера с результатами"""
    try:
        # Получаем текущую позицию прокрутки
        current_scroll = self.driver.execute_script("return arguments[0].scrollTop;", container)
        container_height = self.driver.execute_script("return arguments[0].scrollHeight;", container)
        
        # Прокручиваем контейнер вниз на половину высоты
        self.driver.execute_script("arguments[0].scrollTop = arguments[0].scrollTop + arguments[1];", container, container_height // 2)
        time.sleep(0.3)
        
        # Прокручиваем до конца контейнера
        self.driver.execute_script("arguments[0].scrollTop = arguments[0].scrollHeight;", container)
        time.sleep(0.3)
        
    except Exception as e:
        print(f"   ⚠️ Ошибка прокрутки контейнера: {e}")
        # Резервная прокрутка страницы
        try:
            self.driver.execute_script("window.scrollBy(0, 500);")
            time.sleep(0.3)
        except:
            pass
```

**Изменения:**
- Убраны проблемные `container.send_keys(Keys.PAGE_DOWN)`
- Используется только JavaScript для прокрутки
- Добавлена резервная прокрутка страницы при ошибке

### 2. Улучшен поиск контейнера `find_results_container()`
```python
def find_results_container(self):
    """Поиск контейнера с результатами поиска"""
    # Специфичные селекторы для Яндекс.Карт
    container_selectors = [
        "//div[contains(@class, 'search-list-view')]",
        "//div[contains(@class, 'search-list')]",
        "//div[contains(@class, 'search-results')]",
        # ... и другие селекторы
    ]
    
    # Если не нашли контейнер, пробуем найти по родительскому элементу
    if not container:
        org_links = self.driver.find_elements(By.XPATH, "//a[contains(@href, '/org/')]")
        if org_links:
            first_link = org_links[0]
            parent = first_link.find_element(By.XPATH, "./ancestor::div[contains(@class, 'search') or contains(@class, 'list') or contains(@class, 'result') or contains(@class, 'business') or contains(@class, 'org')][1]")
            if parent and parent.is_displayed():
                return parent
```

**Улучшения:**
- Добавлены дополнительные селекторы
- Поиск по родительским элементам
- Более детальное логирование

### 3. Реструктурирован основной метод `scroll_to_load_more()`
```python
def scroll_to_load_more(self):
    """Прокрутка блока с предприятиями для загрузки больше контента"""
    # Получаем начальное количество элементов
    initial_elements = self.count_business_elements()
    
    # Находим блок с результатами поиска
    results_container = self.find_results_container()
    
    if results_container:
        print(f"   ✅ Найден блок результатов, используем прокрутку контейнера")
        self.scroll_container_method(results_container, initial_elements)
    else:
        print("   ⚠️ Блок результатов не найден, используем прокрутку страницы")
        self.scroll_page_fallback()
```

**Изменения:**
- Разделена логика на два метода
- Более четкое разделение между прокруткой контейнера и страницы
- Улучшенное логирование

### 4. Добавлен отдельный метод `scroll_container_method()`
```python
def scroll_container_method(self, container, initial_elements):
    """Прокрутка через контейнер"""
    scroll_attempts = 0
    max_scrolls = 15  # Уменьшено с 20
    no_change_count = 0
    max_no_change = 3
    
    while scroll_attempts < max_scrolls and no_change_count < max_no_change:
        elements_before = self.count_business_elements()
        self.scroll_results_container(container)
        time.sleep(1.5)
        elements_after = self.count_business_elements()
        
        if elements_after > elements_before:
            print(f"   ✅ Загружено: +{elements_after - elements_before}")
            no_change_count = 0
        else:
            no_change_count += 1
```

**Преимущества:**
- Изолированная логика прокрутки контейнера
- Уменьшено количество прокруток для ускорения
- Более четкий контроль процесса
