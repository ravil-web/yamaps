# Улучшения прокрутки для загрузки больше предприятий

## Проблема
Парсер находил только 5 предприятий из-за неэффективной прокрутки страницы Яндекс.Карт.

## Решение
Создана полностью переработанная система прокрутки с динамическим контролем загрузки контента.

## Новые методы

### 1. `scroll_to_load_more()` - Основной метод прокрутки
```python
def scroll_to_load_more(self):
    """Улучшенная прокрутка для загрузки больше предприятий"""
    # Ждем загрузки страницы
    time.sleep(3)
    
    # Получаем начальное количество элементов
    initial_elements = self.count_business_elements()
    
    scroll_attempts = 0
    max_scrolls = 50  # Увеличено с 20 до 50
    no_change_count = 0
    max_no_change = 5  # Максимум прокруток без изменений подряд
    
    while scroll_attempts < max_scrolls and no_change_count < max_no_change:
        elements_before = self.count_business_elements()
        self.perform_scroll_actions()
        time.sleep(2)
        elements_after = self.count_business_elements()
        
        if elements_after > elements_before:
            print(f"✅ Загружено новых элементов: {elements_after - elements_before}")
            no_change_count = 0
        else:
            no_change_count += 1
            
        scroll_attempts += 1
        
        # Дополнительная проверка кнопок загрузки
        if no_change_count >= 2:
            self.click_load_more_buttons()
```

### 2. `count_business_elements()` - Подсчет элементов
```python
def count_business_elements(self):
    """Подсчет количества элементов предприятий на странице"""
    selectors = [
        "//a[contains(@href, '/org/')]",
        "//div[contains(@class, 'search-result-snippet-view')]",
        "//div[contains(@class, 'business-snippet-view')]",
        "//div[contains(@class, 'orgpage-snippet-view')]",
        # ... и другие селекторы
    ]
    
    max_count = 0
    for selector in selectors:
        elements = self.driver.find_elements(By.XPATH, selector)
        if len(elements) > max_count:
            max_count = len(elements)
    
    return max_count
```

### 3. `perform_scroll_actions()` - Множественные действия прокрутки
```python
def perform_scroll_actions(self):
    """Выполнение различных действий прокрутки"""
    # 1. Прокрутка до конца страницы
    self.driver.execute_script("window.scrollTo(0, document.body.scrollHeight);")
    
    # 2. Прокрутка на половину высоты
    self.driver.execute_script("window.scrollTo(0, document.body.scrollHeight / 2);")
    
    # 3. Прокрутка до конца снова
    self.driver.execute_script("window.scrollTo(0, document.body.scrollHeight);")
    
    # 4. Прокрутка с помощью клавиш
    body = self.driver.find_element(By.TAG_NAME, "body")
    for _ in range(5):
        body.send_keys(Keys.PAGE_DOWN)
        time.sleep(0.5)
    
    # 5. Прокрутка до конца еще раз
    self.driver.execute_script("window.scrollTo(0, document.body.scrollHeight);")
```

### 4. `click_load_more_buttons()` - Поиск и клик кнопок загрузки
```python
def click_load_more_buttons(self):
    """Клик по кнопкам загрузки дополнительного контента"""
    button_selectors = [
        "//button[contains(text(), 'Показать')]",
        "//button[contains(text(), 'Еще')]",
        "//button[contains(text(), 'Загрузить')]",
        "//button[contains(@class, 'load-more')]",
        "//button[contains(@class, 'show-more')]",
        "//a[contains(text(), 'Показать')]",
        "//div[contains(@class, 'load-more')]",
        # ... и другие селекторы
    ]
    
    for selector in button_selectors:
        buttons = self.driver.find_elements(By.XPATH, selector)
        for button in buttons:
            if button.is_displayed() and button.is_enabled():
                self.driver.execute_script("arguments[0].click();", button)
                time.sleep(3)
                return True
```

## Ключевые улучшения

1. **Динамический контроль**: Прокрутка продолжается до тех пор, пока загружаются новые элементы

5. **Подсчет элементов**: Контроль количества загруженных элементов
