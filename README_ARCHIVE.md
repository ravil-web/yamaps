# Парсер Яндекс.Карт - Готовый к использованию

## Описание

Этот архив содержит полностью рабочий парсер для Яндекс.Карт с оптимизированной прокруткой, автоматическим созданием дашбордов и экспортом в Excel.

## Возможности

✅ **Парсинг предприятий** - находит 20+ предприятий за 5 итераций  
✅ **Быстрая работа** - оптимизированная прокрутка  
✅ **Автоматические дашборды** - HTML отчеты с визуализацией  
✅ **Экспорт в Excel** - готовые таблицы для анализа  
✅ **Детальное логирование** - полная информация о процессе  
✅ **Настраиваемость** - гибкая конфигурация  

## Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements_parser.txt
```

### 2. Запуск парсера
```bash
python run_full_cycle.py
```

### 3. Настройка поиска
Отредактируйте URL в `run_full_cycle.py`:
```python
search_url = "https://yandex.ru/maps/39/rostov-na-donu/search/стоматология/?ll=39.806284%2C47.275656&z=12"
```

## Конфигурация

### Настройка количества предприятий
В `config.py`:
```python
TARGET_BUSINESSES_COUNT = 0  # 0 = все найденные, или конкретное число
```

### Настройка браузера
```python
HEADLESS_MODE = False  # True для работы без окна браузера
BROWSER_TIMEOUT = 30   # Таймаут ожидания элементов
```

## Результаты

После парсинга создаются:

1. **JSON файл** с данными предприятий
2. **HTML дашборд** с визуализацией
3. **Excel файл** для анализа
4. **Логи** процесса парсинга

## Устранение проблем

### ChromeDriver не найден
```bash
pip install --upgrade webdriver-manager
```

### Медленная работа
1. Установите `HEADLESS_MODE = True` в `config.py`
2. Закройте другие программы
3. Увеличьте `BROWSER_TIMEOUT`

### Парсер не находит предприятия
1. Проверьте URL поиска
2. Увеличьте `TARGET_BUSINESSES_COUNT`
3. Проверьте интернет-соединение

## Системные требования

- **Python**: 3.8+
- **ОС**: Windows 10/11, macOS, Linux
- **Память**: 4 ГБ RAM
- **Место**: 500 МБ свободного места

## Поддержка

При проблемах:
1. Проверьте логи в `parsing_results/`
2. Убедитесь в установке всех зависимостей
3. Проверьте версию Python (3.8+)
4. Убедитесь в наличии Chrome/Chromium
