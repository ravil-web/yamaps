# 🏥 Парсер стоматологических клиник - ФИНАЛЬНАЯ ВЕРСИЯ

## ✅ Готовое решение

Полнофункциональный парсер с именованными сессиями, аккордеон-дашбордом и автоматической организацией данных.

## 🚀 Быстрый старт

### 1. Установка зависимостей:
```bash
pip install -r requirements_full.txt
```

### 2. Основной парсинг:
```bash
python main.py
# Введите имя: "Стоматология_Ростов_2025"
```

### 3. Полный цикл (парсинг + дашборд):
```bash
python run_full_cycle.py
# Автоматический запрос имени + создание дашборда
```

### 4. Создание дашборда для существующей сессии:
```bash
python generate_dashboard.py
# Интерактивный выбор сессии
```

## 📂 Структура результатов

```
parsing_results/
├── Стоматология_Ростов_2025/          ← Ваша именованная сессия
│   ├── businesses/                    ← Данные предприятий (JSON, CSV)
│   ├── logs/                          ← Логи парсинга
│   └── client_dashboard_2025...html   ← 📊 ВАШ ДАШБОРД (откройте в браузере)
```

## 🛠️ Полезные скрипты

*   `python src/scripts/create_client_dashboard.py` — Создать дашборд вручную (если забыли или хотите обновить)

## ⚙️ Конфигурация

### config.py:
```python
# Количество предприятий
TARGET_BUSINESSES_COUNT = 10

# URL поиска (можно менять город/тип)
SEARCH_URL = "https://yandex.ru/maps/39/rostov-na-donu/search/..."

# Задержки парсинга
DELAYS = {
    'page_load': 5,
    'scroll': 1,
    'element_click': 2
}
```

## 📋 Основные команды

```bash
# Основной парсинг с именем сессии
python main.py

# Полный цикл (парсинг + дашборд + открытие)
python run_full_cycle.py

# Дашборд для конкретной сессии
python generate_dashboard.py --session "имя_сессии" --open

```

## 🚨 Решение проблем

### Парсер не находит предприятия:
1. Проверьте URL в `config.py`
2. Увеличьте задержки в `DELAYS`
3. Проверьте интернет-соединение

### Дашборд не создается:
1. Убедитесь что есть данные в сессии
2. Проверьте права на запись
3. Установите зависимости: `pip install pandas plotly`

### Ошибки импорта:
```bash
pip install -r requirements_full.txt
```
